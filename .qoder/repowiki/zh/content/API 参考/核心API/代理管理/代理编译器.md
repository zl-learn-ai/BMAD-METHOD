## 简介

BMAD代理编译器是一个强大的工具链，负责将YAML格式的代理配置文件转换为可执行的XML格式。该编译器实现了从元数据定义到运行时对象的完整转换过程，支持复杂的条件触发、多级菜单和动态提示等高级功能。

编译器的核心价值在于：
- **类型安全**：通过严格的Schema验证确保配置正确性
- **模板化**：支持条件逻辑和变量替换的模板处理
- **模块化**：支持核心代理和模块代理的不同处理路径
- **兼容性**：同时支持IDE和Web部署环境

   - 检查缩进和冒号使用

   - 检查字段类型是否正确
   - 验证必填字段是否存在

3. **模板变量错误**
   - 检查变量名拼写
   - 验证变量作用域
   - 确认默认值设置

4. **文件引用问题**
   - 验证文件路径正确性
   - 检查文件权限
   - 确认文件编码格式
